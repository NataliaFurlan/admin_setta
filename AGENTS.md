# Instrucoes do repositorio

## Commits

- Use o formato `[PALAVRA-CHAVE] - mensagem breve sobre o que foi feito`.
- Exemplos de palavras-chave: `ADD`, `AJUSTE`, `FIX` e `EXCLUDED`.
- Commits feitos em nome da proprietaria devem usar `Natália Cardoso Furlan <nataliafurlan88@gmail.com>` como autoria, nunca `Codex`.
